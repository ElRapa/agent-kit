# Kit help

The owner does not memorize skills; you know them so the owner doesn't have to.

- "What do I have?": read the "Skills: which one when" table in the global AGENTS.md (agent-kit) and
  list the skills by situation, one line each, in plain words. Mention the project's own skills too
  (`.agents/skills/`, `.claude/skills/`).
- "What fits X?": name one skill (two at most), say in one sentence why, and offer to start it now.
  If nothing fits, say so; do not stretch a skill.
- Unsure which situation it is: pick the likely one and say which you picked.

Keep the answer short. The point is to start the work, not to read a catalog.
